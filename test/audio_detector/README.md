# Audio Detector Synthetic Unit Tests (Phase 5)

This directory contains deterministic synthetic unit tests for the platform-independent PCM16 mono Audio Detector (`paxg::audio::PcmAudioDetector`).

## Test Coverage

1. **`test_ring_buffer_basics_and_bounds`**:
   - Empty/full states, capacity limits, available sample tracking, free space computation.
   - Pushing, peeking without advancing read pointer, popping.
   - Rejection/dropping on full buffer without memory violations.

2. **`test_ring_buffer_overwrite_and_wraparound`**:
   - Push-overwrite behavior when buffer saturates.
   - Head and tail ring index wraparound.
   - Deterministic preservation of newest samples and bounded sample count.

3. **`test_rms_and_peak_accuracy`**:
   - Verification against ground truth mathematical waveforms:
     - Digital silence (0): RMS = 0.0, Peak = 0.
     - Pure DC offset (+1200): RMS = 1200.0, Peak = 1200.
     - Symmetric square wave (+3000, -3000): RMS = 3000.0, Peak = 3000.
     - Single impulse at `INT16_MIN` (-32768): Peak = 32768 (stored in `uint32_t peak`, computed via `int32_t` abs to avoid signed overflow and int16 narrowing).
     - Pure DC at `INT16_MIN` (-32768): RMS = 32768.0, Peak = 32768.
     - Pure DC at `INT16_MAX` (+32767): RMS = 32767.0, Peak = 32767.

4. **`test_adaptive_noise_floor`**:
   - Exponential Moving Average (EMA) tracking of steady ambient noise.
   - Burst immunity: sudden loud bursts are prevented from corrupting the baseline noise floor.

5. **`test_transient_noise_debounce_rejection`**:
   - Deterministic rejection of single-frame transient noise spikes shorter than `debounceFrames` (e.g. 1 frame spike rejected when 2 consecutive frames required).

6. **`test_valid_burst_trigger`**:
   - Sustained burst of >= `debounceFrames` above dynamic threshold correctly fires trigger and increments `triggerCount`.

7. **`test_cooldown_rejection`**:
   - Secondary bursts arriving during the mandatory `cooldownFrames` lockout are rejected, preventing double-triggering.

8. **`test_cooldown_expiration_and_rearm`**:
   - After cooldown frames expire, the detector re-arms and cleanly triggers on subsequent valid sound bursts (`triggerCount` increments to 2).

9. **`test_synthetic_scenario_end_to_end`**:
   - End-to-end continuous 1280-sample PCM stream with ambient noise, injected burst, and post-burst ambient noise generated by `SyntheticAudioGenerator::generateBurst`.

10. **`test_fishing_settings_bounds_clamping`**:
    - Verification of NVS persistent settings clamping logic:
      - Sane default validation (`threshold=1500`, `timeout=20000ms`, `cooldown=2000ms`, `castKey='1'`, `interactKey='2'`).
      - Minimum bound clamping (`500`, `5000ms`, `500ms`).
      - Maximum bound clamping (`5000`, `30000ms`, `5000ms`).
      - Key validation: invalid characters mapped back to default placeholders; allowed keys preserved.

11. **`test_fsm_normal_bite_flow`**:
    - Deterministic verification of the complete nonblocking FSM state sequence via production `FishingStateMachine`:
      `IDLE -> CASTING -> WAITING -> BITE_DETECTED -> REELING -> COOLDOWN -> CASTING`.
    - Real detector ingestion and latch confirmation on synthetic bite burst.

12. **`test_fsm_timeout_flow`**:
    - Deterministic verification of cast timeout transition via production `FishingStateMachine`:
      `WAITING` without bite trigger advances to `waitTimeoutMs` -> transitions to `TIMEOUT` -> `COOLDOWN`.

13. **`test_fsm_pause_resume_flow`**:
    - Verification of user pause/resume and stop sequence via production `FishingStateMachine`:
      Active running state transitions to `PAUSED`, invalid events rejected, resume transitions back to `CASTING`, stop transitions to `IDLE` (including idempotent stop).

14. **`test_fsm_error_and_disarm_flow`**:
    - Verification of error handling and safe disarm via production `FishingStateMachine`:
      Error event forces state to `ERROR`, invalid actions rejected, and stop transitions state back to `IDLE`.

15. **`test_fsm_invalid_transitions_rejection`**:
    - Systematic negative verification across all 9 states:
      Asserts that out-of-order or invalid event dispatches return `false` and leave state unmodified across `IDLE`, `CASTING`, `WAITING`, `BITE_DETECTED`, `REELING`, `COOLDOWN`, `TIMEOUT`, `PAUSED`, and `ERROR`.

## Host Execution & Validation Harness Notice

The validation script `test/usb_audio_poc/run_validation.py` tests the detector test source together with its full implementation sources (`src/audio/pcm_audio_detector.cpp`, `src/audio/synthetic_audio_samples.cpp`):
- If a native host C++ compiler (`g++`, `clang++`, or `cl.exe`) is detected on host PATH, the harness compiles and links the native executable, executes all test assertions, and reports passed/failed counts.
- When building in an environment without a native host compiler on PATH, test assertions are **not executed on host**. The harness explicitly reports this condition and performs a strict cross-compilation check (`xtensa-esp32s3-elf-g++ -Wall -Wextra -Werror`) labeled as **compile-only** without claiming that unit tests passed. All temporary files (`.o`, `.elf`, `.exe`) are cleaned up upon completion.
